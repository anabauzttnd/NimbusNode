# NimbusNode

NimbusNode enables auto-scaling, event-driven data processing across a distributed, cloud-based cluster, utilizing a scalable engine architecture.

NimbusNode is built to be simple and practical, focusing on doing one thing well.

**Why NimbusNode?**

- NimbusNode enables auto-scaling, event-driven data
- processing across a distributed, cloud-based
- cluster, utilizing a scalable engine

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/NimbusNode.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
